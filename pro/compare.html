Hosted AI credits

Active Pro includes up to 45 daily credits and 1,000 monthly credits for hosted AI. These are credit limits, not a guaranteed number of reviews. Daily credits reset at midnight and monthly credits reset on the first day of the month, in Asia/Riyadh. A separate monthly hosted allowance can also stop hosted reviews before your credits run out.

Charges are dynamic: larger proof files and longer reviews use more credits. Each task contributes its own charge. A reference-example comparison applies a ×2 multiplier to that task’s charge. A batch of two or more tasks receives a 25% per-task batch discount, including tasks with a reference example.

Before you start, a dialog shows the estimated credit charge and maximum temporary hold, rounded to one decimal place. Open “View details” for three-decimal totals, task charges, reference multipliers, and batch discounts. Rounding only affects the display.

The final charge will not exceed the quoted maximum. Unused held credits return to your balance. A completed review is charged even when proof is rejected. Cancel at the preview to stop before a paid review starts.

You can attach up to five proof files. Hosted uploads have size and processing limits; large uploads may need to be split. Batch results are shown per task, and eligible completions still require your confirmation.

Personal API-key mode

Save your own supported provider API key in Settings to review a task’s proof using that provider. Personal API-key reviews are separate from hosted credits. Your provider’s usage limits and charges apply.

Free accounts use their personal key for proof reviews. Active Pro accounts can choose personal API-key mode instead of hosted AI. Switching modes does not reset hosted credit balances or limits. Hosted batch reviews require hosted mode.

Consecutive subtask creation

With active Pro, select the Pro consecutive option and type a title such as “Chapter {num==1}”. After adding that subtask, the next title advances to “Chapter {num==2}”. The option is available in both Create Task and Task Details.

If Pro expires, existing subtasks and their numbering stay intact. You can still create subtasks manually and type numbered titles. If entitlement checking is unavailable, manual creation remains available and the Pro option shows a retry message.
