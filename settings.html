Connection

Checking your phone connection…

In MacroDroid, add an HTTP Request action and paste in these two values.

Add a header named Authorization with the value Bearer <your token>.

    Free accounts can connect 3 devices, Pro accounts 12. If Pro ends, only your first 3 keep working and the rest show as revoked until you renew.

    You can only change these when today's tasks are done, during a break, or while Emergency Bypass is on.

    Add a device first. The Bridge download has the new token built in, so it only works for the device you just added.

    Download didn't work? Add the token by hand
    1. Download the Bridge anyway (or use the one from the blocker guide) and import it into MacroDroid.
    2. Swipe up the "Local Variables" drawer and select "user token".
    3. Replace the value of the variable with your token from above. Tokens begin with tkp_.

    The Bridge file you get without a token has this variable empty, so these steps always work.
