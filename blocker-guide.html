📲 Automated Phone Lockdown Guide

Follow this guide to bind your Android device to Taskitator. Your phone will automatically remain completely blocked until all today's tasks are verified or an approved break window is active.

How It Works

The system works through two independent macros inside MacroDroid:

  1. Macro 1 (The Blocker): An aggressive macro that kicks you to the Home Screen or launches Taskitator whenever you try to open social media, games, or distracting apps.
  2. Macro 2 (The Cloud Bridge): A background poller that checks Taskitator every 5 minutes. If all tasks are completed or you are on break, it automatically disables Macro 1. If tasks remain, it turns Macro 1 back on.
Step 1

Build the Blocker Macro (Macro 1)

If you already have a functional blocker macro, skip to Step 2. Otherwise, create it in MacroDroid:

Macro Name: App Blocker

🔴 TRIGGERS:
  • Applications → Application Launched → Select distracting apps (Instagram, YouTube, X, Games, etc.)

🔵 ACTIONS:
  • Device Settings → Home Screen (Force exit to home)
  • (Optional) Applications → Launch Application → Select Taskitator Web/PWA
  • Notification → Display Pop-Up Message → "Tasks incomplete! Complete them first."
⚠️ Anti-Lockout Rule: Never add the Phone Dialer, SMS/Messages, Settings, or MacroDroid itself to the blocked applications list during testing.
Step 2

Build the Cloud Bridge Macro (Macro 2)

This is the brain that queries the Taskitator cloud server.

  1. Open MacroDroid → tap Add Macro.
  2. Name it: Taskitator Cloud Bridge.
  3. Tap the Variables bar at the bottom drawer → tap + → Name: http_response → Type: String → OK.
  4. Add the 3 Triggers (Red section):
    • Regular Interval: Time/Date → Regular Interval → 5 Minutes.
    • Screen Unlock: Device Events → Screen On / Screen Unlocked → Screen Unlocked.
    • Connectivity: Connectivity → Network Connected → Any Network.
  5. Add the HTTP Request Action (Blue section):
    • Tap + → Web / HTTP → HTTP Request.
    • Request Type: GET.
    • URL: Copy from the Settings page:
      https://taskitator-sync.spacexmzez.workers.dev/?action=status&format=text
    • Headers: Tap + to add a header:
      Header: Authorization
      Value: Bearer YOUR_TOKEN_FROM_SETTINGS
    • Check Block next actions until complete.
    • Check Save HTTP response to string variable → pick http_response.
  6. Add the If / Else Branching:
    ▼ If (http_response contains "device_unlocked = true")
        ► MacroDroid Specific → Macro Enable/Disable → Disable [App Blocker]
    ▼ Else
        ► MacroDroid Specific → Macro Enable/Disable → Enable [App Blocker]
    ▲ End If
Step 3

Linking with Taskitator Settings

To get your live URL and Bearer token:

  1. Go back to Settings.
  2. Ensure you are logged into your sync account.
  3. Look at the MacroDroid Lock Integration card.
  4. Tap Copy next to the Status URL and paste it into MacroDroid's URL input.
  5. Tap Copy next to the Authorization Header Token and paste it after Bearer in MacroDroid's Headers section.
Step 4

Testing the Lock

Inside the MacroDroid macro editor for Taskitator Cloud Bridge:

  • Tap the three dots in the upper right → tap Test Actions.
  • Check your App Blocker macro on MacroDroid's main screen:
    • If you have pending tasks for today, its toggle will automatically turn ON.
    • If all tasks are checked off, its toggle will turn OFF.
