Phase 1: Macro 1

Building the App Blocker

This macro monitors your device and immediately terminates distracting apps whenever tasks remain unfinished. Complete the checkpoints below.

Change which apps are blocked
  1. In MacroDroid → Macros, open your App Blocker macro.
  2. Tap its Application Launched/Closed trigger and choose Configure or Edit (wording varies by version).
  3. Keep Application Launched selected. Tick apps to add them, untick apps to remove them, confirm the selection and save the macro with the checkmark.
  4. When App Blocker is enabled, launch a selected app to check that it returns you to the home screen. A removed app should open normally.

Keep MacroDroid and the browser you use for Taskitator out of the blocked-app list so you can manage the setup. The Cloud Bridge does not choose or change blocked apps.

Phase 2 · Download option

Import the Cloud Bridge

The download contains only the bridge. Your App Blocker stays manual. This template starts disabled and contains a token placeholder.

↓ Download macro

After downloading, open MacroDroid → Export/Import → Import (or Storage under Import), then choose Taskitator-Cloud-Bridge.macro from Downloads. You can also try opening the file with MacroDroid from your file manager. Menu labels vary by version.

Change these settings after import

  1. Keep it disabled while configuring. Open the imported Taskitator Cloud Bridge. If you already have a working bridge, keep only one bridge enabled after setup.
  2. Add your phone token. In Taskitator → Settings → Account, find Authorization Header Token. Use your existing saved phone token, or generate a new one if you no longer have it. New tokens are shown once and replace the old phone token immediately; pause blocking first and update every device using the old token. In the imported macro's HTTP Request → Header Params, edit Authorization to Bearer YOUR_PHONE_TOKEN (one space). Replace the placeholder; never use a Clerk session token, account password or AI API key.
  3. Confirm the Status URL. HTTP Request should use GET and the exact Status URL shown in Taskitator Settings. This template uses:https://taskitator-sync.spacexmzez.workers.dev/?action=status&format=textKeep Block next actions until complete on. Leave certificate validation enabled.
  4. Select your App Blocker in both branches. Tap each Enable/Disable Macro action and configure it to target the App Blocker you built on this phone. Re-select it even if the imported name already says App Blocker; the original file includes another device's macro reference. Under If, choose Disable App Blocker. Under Else, choose Enable App Blocker.
  5. Keep the response variable consistent. The download uses a local String named http_response for both the HTTP response and the If condition. No global response variable is needed for this download option. If MacroDroid asks you to choose a variable, select that same local String in both places. The condition must match device_unlocked = true. The manual option below uses its own global-variable instructions instead.
  6. Check the triggers. The template checks every 5 minutes and when the screen turns on. Keep these defaults, or edit Regular Interval if you want a different polling interval.
  7. Save, test, then enable. Save the macro, use its Test actions option (or your version's equivalent), and check http_response. Confirm both states below before leaving the bridge enabled. Grant the Android permissions requested by your chosen triggers and App Blocker actions.

Import or connection not working?
  • The browser shows file text: use its Download / Save link option and keep the .macro extension. Import the saved file from MacroDroid. If your host returns a missing-file page, upload pro/taskitator-cloud-bridge.macro alongside this guide.
  • Import fails: update MacroDroid and select the actual downloaded .macro file, not an HTML error page. You can always use the manual guide below.
  • 401 / Unauthorized: check the phone token and Bearer prefix. Replacing or revoking a phone token invalidates the old one.
  • UnknownHostException / unable to resolve host: check the URL, internet connection and DNS. This is a connection error, not a Taskitator unlock response.
  • Response is correct but blocking is wrong: reselect your local App Blocker in both actions, confirm Disable under If and Enable under Else, and confirm that App Blocker's launched-app trigger contains the apps you intend to block.

The template was checked as JSON and against this project's status response. Import and execution on Android still need a device test. See MacroDroid's import/export overview.
